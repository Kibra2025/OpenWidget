# Changelog

## 1.7.0 — 2026-10-16

First public OpenWidget release, based on DeskHardwareWidget 1.6.3.

- OpenWidget branding, executable and portable package names.
- CPU, multi-GPU, RAM and network desktop monitoring with history graphs.
- Independent battery widget for the PC and supported accessories.
- Logitech HID++ battery reads through compatible Bluetooth, Bolt and Unifying interfaces.
- DualSense and DualSense Edge battery reads over USB and Bluetooth, with connection-change refresh.
- Independent position, visibility and click-through settings; optional elevated Windows startup.
- English project overview, detailed Italian manual, MIT license and expanded dependency notices.
- Clean release packaging with SHA-256 checksums and Windows CI / tagged release workflows.

Existing local settings and startup task identifiers remain compatible.
